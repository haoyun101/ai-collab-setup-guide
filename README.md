# AI 协作与文件体系搭建向导

这个 Skill 是多 AI 协作项目的**「项目管家」**。

当你同时用多个 AI 模型或开着多个对话窗口推进一个项目，文件散落找不到、不同 AI 的分工说不清、每次切窗口都得重新交代前因后果，这个向导就能帮上忙。

它会手把手带你搭建一套本地文件体系和交接规则。文件有固定位置，每个 AI 清楚自己负责什么，换窗口时也能沿着已有进度接着做。

它适用于**人与 AI**、**AI 与 AI** 之间的项目协同。单人文件整理和真人团队的流程设计超出这份向导的适用范围。

## 开始使用

1. 在仓库首页选择 **Code → Download ZIP**，解压后将整个目录放入你的 AI 工具的 Skill 安装目录。
2. 在工具中调用 `ai-collab-setup-guide`，从 [SKILL.md](SKILL.md) 开始。
3. 已安装的向导可按开头的说明运行升级自检。检测到更高版本时会自动更新，无法联网时可以继续使用本地版本。
