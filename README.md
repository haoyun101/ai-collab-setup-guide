# AI 协作与文件体系搭建向导

本 Skill 面向多 AI 模型、多会话窗口协同工作场景，用于搭建适配 AI 之间交接流转的本地项目文件体系、角色分工、版本规范与交接流程。

适用于理顺多 AI 协作链路、规范项目本地文件存放规则、统一版本管理方案、降低不同 AI 会话之间重复上下文交底成本的需求。 仅服务 AI 之间的协同流转，**不适用于单人零散文件整理、单次临时文档修改，也不用于真人团队业务流程设计**。

核心定位为项目搭建向导，落地「多 AI 协作 + 本地文件管理」完整工作流直至流程跑通；工作边界严格限定于多个 AI 模型 / 会话窗口之间的协同，不含真人协作流程。

## 开始使用

1. 在仓库首页选择 **Code → Download ZIP**，解压后将整个目录放入你的 AI 工具的 Skill 安装目录。
2. 在工具中调用 `ai-collab-setup-guide`，从 [SKILL.md](SKILL.md) 开始。
3. 已安装的向导可按开头的说明运行升级自检。检测到更高版本时会自动更新，无法联网时可以继续使用本地版本。
